# Componentes de red

## Roles de host

Cada computadora en una red se llama **host** o dispositivo final.

- **Servidor** — computadora que proporciona información a los hosts o clientes: servidores de correo electrónico, web, de archivos
- **Cliente** — el equipo que envía solicitudes a los servidores para recuperar información

## Punto a punto (peer to peer)

Arquitectura en la que cada canal de datos se usa para comunicar únicamente **dos** computadoras, en oposición a las redes multipunto, donde cada canal puede comunicar diversos nodos.

Diseño recomendado para redes **muy pequeñas**.

| ✅ Ventajas | ❌ Desventajas |
|---|---|
| Fácil de configurar | Administración no centralizada |
| Menos complejas | No son tan seguras |
| Reducen costos | No son escalables |
| Ideal para tareas simples | Rendimiento más lento |

## Dispositivos finales

Un **terminal** es el punto donde un mensaje se origina o se recibe. Los datos se originan en un dispositivo final y fluyen por la red hasta llegar a otro dispositivo final.

## Dispositivos intermedios

Interconectan dispositivos finales: switches, puntos de acceso inalámbrico, routers y firewalls.
