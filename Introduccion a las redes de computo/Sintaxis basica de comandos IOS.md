# Sintaxis básica de comandos IOS

> Clase del 11/03/26

La estructura de un comando en la CLI de un dispositivo Cisco tiene cuatro partes:

1. **Prompt** — `switch`
2. **Comando** — `show`
3. **Espacio**
4. **Palabra clave o argumento** — `ip-protocols`

## Ejemplo

```
switch> show ip-protocols
```

## Nota sobre el prompt

El símbolo del prompt indica el modo:
- `>` — modo EXEC usuario
- `#` — modo EXEC privilegiado
