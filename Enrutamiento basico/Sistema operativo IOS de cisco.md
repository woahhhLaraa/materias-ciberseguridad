internet operative system

Desarrollado por cisco, como un paquete de funciones de enrutamiento, conmutamiento, trabajo de internet y telecomunicaciones que se integra estrechamente con un sistema operativo multitarea

Conformado por
- Shell
- Hardware
- Kernel

Sus funciones principales
- Seguridad
- Orientacion
- QoS
- Direccionamiento
- Admnistracion de recursos
- Interfaz

El shell de este OS nos permite teclear comandos para modificar el comportamiento de los routers o switches CISCO mediante tres modos

Modo usuario/normal
	El mas limitado de todos, para acciones simples como consultas, sin escribir nada para evitar errores, un acceso restringido
Modo privilegiado
	Modo de configuracion  de archivos, escritura de ellos, borrar o crear datos
Modo exec line
	Modo especifico, usado para la configuracion del propio switch o router, contrasenas, etc

Se puede entrar al sistema operativo a traves de una computadora, existen 3 formas
	Shell a traves de puerto de consola
	Shell a traves de puerto auxiliar
	Shell a traves de SSH
