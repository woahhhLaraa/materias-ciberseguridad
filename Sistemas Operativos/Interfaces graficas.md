# Interfaces graficas

Si bien una computadora es manipulable a traves de una consola de comandos en un shell, esto no significa que sea sencillo, especialmente para usuarios no tecnicos, y con el boom de las computadoras personales, se tuvo que buscar una solucion a las interfaces complicadas de comandos.

**GUI**  
La interfaz mas comun en los sistemas operativos para usuarios finales, significa literalmente GRAPHIC USER INTERFACE, un sistema de comunicacion entre el usuario y el hardware donde todo es visual, todo tiene botones, eliminando por completo la necesidad de tener comandos

**NUI**  
Natural user interface o interfaz natural de usuario, busca eliminar el uso de perifericos para comunicarse con una computadora, recayendo completamente en movimientos naturales para el ser humano, mover las manos, los brazos, los dedos, comandos de voz.
